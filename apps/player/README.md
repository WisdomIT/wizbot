# wizbot player

노래 신청 기능의 송출을 담당하는 데스크톱 앱입니다. OBS 브라우저 소스 대신 쓸 수 있습니다.

## 무엇이 다른가

- **유튜브 로그인을 앱이 기억합니다.** 프리미엄 계정으로 한 번 로그인해두면 광고 없이 재생됩니다
- OBS 없이도 동작하고, 창을 닫아도 트레이에 남아 재생을 계속합니다
- 전역 단축키로 다른 프로그램을 쓰는 중에도 조작할 수 있습니다

화면은 사이트의 뮤직플레이어와 같습니다 — 앱이 사이트를 그대로 띄우기 때문입니다.

## 창 모드

| 모드 | 크기 |
|---|---|
| 미니 플레이어 (기본) | 고정. 대기열을 열면 세로만 조절 가능 |
| 큰 창 | 자유롭게 조절 (하한 있음) |

미니 플레이어의 `⛶` 버튼으로 큰 창, 큰 창 위쪽의 버튼으로 다시 미니로 돌아옵니다.
미니 플레이어는 볼륨·구간 이동 슬라이더를 뺀 나머지를 잡고 끌면 창이 움직입니다.

타이틀바는 앱이 직접 그리고 **창 제어 버튼만 OS 것을 씁니다** — macOS 는 신호등 버튼,
Windows 는 시스템이 그려주는 오버레이 버튼입니다. OS 마다 크기·위치가 다른 버튼을
직접 흉내 내면 어긋나기 때문입니다.

로그아웃은 플레이어의 **설정 → 로그아웃**에 있습니다.

## 쓰는 법

1. 앱을 켜고 **치지직 계정으로 로그인**합니다 (웹과 같은 로그인)
2. 콘솔 또는 앱의 설정에서 **송출 소스를 「위즈봇 플레이어 앱」으로** 바꿉니다
3. 광고 없이 듣고 싶다면 유튜브에 로그인해둡니다 (프리미엄 계정)

### 전역 단축키

기본값은 다음과 같고, **설정에서 조합을 바꿀 수 있습니다.**

| 단축키 | 동작 |
|---|---|
| `Ctrl/Cmd + Shift + P` | 재생 / 일시정지 |
| `Ctrl/Cmd + Shift + S` | 정지 |
| `Ctrl/Cmd + Shift + N` | 다음 곡 |

설정의 **전역 단축키**를 끄면 등록되지 않습니다. 다른 프로그램이 같은 조합을 이미 쓰고 있으면 그 단축키만 동작하지 않습니다. 조합을 바꾸면 앱이 10초 안에 다시 등록합니다.

## ⚠️ 설치 시 경고

**코드 서명 인증서가 없어서** 설치할 때 운영체제가 경고를 띄웁니다. 앱에 문제가 있어서가 아니라, 서명되지 않은 프로그램에 공통으로 나오는 경고입니다.

**Windows** — 「Windows의 PC 보호」 화면에서 `추가 정보` → `실행`

**macOS** — 처음 실행할 때 「확인되지 않은 개발자」로 차단됩니다.
앱을 **우클릭 → 열기** 로 실행하고 한 번 더 `열기` 를 누르세요. 그래도 막히면
`시스템 설정 → 개인정보 보호 및 보안` 아래쪽의 `확인 없이 열기` 를 누릅니다.

## 한 번에 한 곳에서만

송출 소스는 한 번에 하나만 재생합니다. 앱을 여러 PC 에서 켜두면 **먼저 잡은 쪽이 계속 재생**하고
나머지는 대기합니다. 재생하던 쪽을 끄면 15초 안에 다른 쪽이 이어받습니다.
OBS 브라우저 소스를 함께 열어둔 경우에는 설정에서 지정한 소스만 재생합니다.

## 아이콘 파일

리포지토리에 아이콘 원본을 두지 않았다. 아래 위치에 넣으면 빌드에 그대로 쓰인다.

| 경로 | 규격 | 쓰임 |
|---|---|---|
| `build/icon.png` | **1024×1024** PNG | 앱 아이콘 (electron-builder 가 .ico/.icns 로 변환) |
| `resources/trayTemplate.png` | **16×16** PNG, 검정 단색 + 투명 배경 | macOS 메뉴 막대 |
| `resources/trayTemplate@2x.png` | **32×32**, 위와 같은 그림 | macOS 레티나 |
| `resources/tray.png` | **32×32** PNG, 컬러 | Windows 트레이 |

macOS 메뉴 막대 아이콘은 **템플릿 이미지**여야 한다 — 색은 무시되고 **알파(모양)만** 쓰이며,
다크/라이트 모드에 맞춰 시스템이 흑백을 뒤집는다. 그래서 컬러 로고를 그대로 넣으면 검은 덩어리로 보인다.

트레이 아이콘 파일이 없으면 **트레이를 만들지 않는다.** 빈 이미지로 `Tray` 를 만들면 macOS 에서
시작하자마자 죽기 때문이다.

## 개발

```bash
pnpm --filter @wizbot/player dev          # 빌드 후 실행
WIZBOT_SITE_URL=http://localhost:3001 pnpm --filter @wizbot/player dev   # 로컬 사이트로
pnpm --filter @wizbot/player package      # 현재 OS 용 설치 파일 생성 (release/)
```

메인 프로세스는 `src/` 한 곳뿐입니다. 화면은 전부 사이트(`/app/player`)가 그리고, 소리는 숨은 창(`/app/source`)이 담당합니다.
