# 위즈봇 플레이어

노래 신청 기능의 송출을 담당하는 데스크톱 앱입니다. OBS 브라우저 소스 대신 쓸 수 있습니다.

## 무엇이 다른가

- **유튜브 로그인을 앱이 기억합니다.** 프리미엄 계정으로 한 번 로그인해두면 광고 없이 재생됩니다
- OBS 없이도 동작하고, 창을 닫아도 트레이에 남아 재생을 계속합니다
- 전역 단축키로 다른 프로그램을 쓰는 중에도 조작할 수 있습니다

화면은 사이트의 뮤직플레이어와 같습니다 — 앱이 사이트를 그대로 띄우기 때문입니다.

## 쓰는 법

1. 앱을 켜고 **치지직 계정으로 로그인**합니다 (웹과 같은 로그인)
2. 콘솔 또는 앱의 설정에서 **송출 소스를 「위즈봇 플레이어 앱」으로** 바꿉니다
3. 광고 없이 듣고 싶다면 유튜브에 로그인해둡니다 (프리미엄 계정)

### 전역 단축키

| 단축키 | 동작 |
|---|---|
| `Ctrl/Cmd + Shift + P` | 재생 / 일시정지 |
| `Ctrl/Cmd + Shift + S` | 정지 |
| `Ctrl/Cmd + Shift + N` | 다음 곡 |

설정의 **노래 단축키 사용**을 끄면 등록되지 않습니다. 다른 프로그램이 같은 조합을 이미 쓰고 있으면 그 단축키만 동작하지 않습니다.

## ⚠️ 설치 시 경고

**코드 서명 인증서가 없어서** 설치할 때 운영체제가 경고를 띄웁니다. 앱에 문제가 있어서가 아니라, 서명되지 않은 프로그램에 공통으로 나오는 경고입니다.

**Windows** — 「Windows의 PC 보호」 화면에서 `추가 정보` → `실행`

**macOS** — 처음 실행할 때 「확인되지 않은 개발자」로 차단됩니다.
앱을 **우클릭 → 열기** 로 실행하고 한 번 더 `열기` 를 누르세요. 그래도 막히면
`시스템 설정 → 개인정보 보호 및 보안` 아래쪽의 `확인 없이 열기` 를 누릅니다.

## 개발

```bash
pnpm --filter @wizbot/player dev          # 빌드 후 실행
WIZBOT_SITE_URL=http://localhost:3001 pnpm --filter @wizbot/player dev   # 로컬 사이트로
pnpm --filter @wizbot/player package      # 현재 OS 용 설치 파일 생성 (release/)
```

메인 프로세스는 `src/` 한 곳뿐입니다. 화면은 전부 사이트(`/app/player`)가 그리고, 소리는 숨은 창(`/app/source`)이 담당합니다.
