시청자가 채팅에 `!이름` 을 입력하면 챗봇이 응답합니다. 명령어는 두 종류입니다.

| 종류 | 하는 일 | 예 |
|---|---|---|
| **단순 응답 (echo)** | 정해둔 문구로 답합니다 | `!디스코드` → 초대 링크 |
| **기능 (function)** | 위즈봇 기능을 실행합니다 | `!노래 신청 <곡>`, `!방제 수정 <제목>` |

봇 › **명령어**에서 추가·수정·삭제하고, 스위치로 잠시 꺼둘 수도 있습니다(끈 명령어는 없는 것처럼 동작합니다). 기능 명령어의 종류별 사용법은 [기능 명령어 안내](/manual/chatbot-functions)를 참고하세요.

## 이름 규칙

- 이름에 **띄어쓰기를 쓸 수 있습니다** — `노래 신청`, `멤버 수정` 처럼. 최대 20자입니다.
- 유일성은 **정확히 같은 이름** 기준입니다. `멤버` 와 `멤버 수정` 은 서로 다른 이름이라 함께 둘 수 있습니다. echo 와 기능 명령어 사이에도 같은 이름은 쓸 수 없고, 꺼둔 명령어의 이름도 차지된 상태입니다.
- 채팅에서는 **가장 긴 이름부터** 맞춰봅니다. `멤버` 와 `멤버 수정` 이 있으면 `!멤버 수정 내용` 은 「멤버 수정」이, `!멤버` 는 「멤버」가 응답합니다.
- 명령어 뒤에 인수를 붙일 때는 **공백으로 구분**해야 합니다. `!노래신청곡` 처럼 붙여 쓰면 인식되지 않습니다.
- 대소문자는 구분합니다.

## 권한

기능 명령어는 누가 쓸 수 있는지 정합니다 — **시청자**(모두) / **매니저**(치지직 채널 관리자 이상) / **스트리머**(본인만). 단순 응답(echo) 명령어는 권한 구분 없이 누구나 쓸 수 있습니다.

## 기본으로 만들어지는 명령어

처음 시작하면 아래 명령어가 준비되어 있습니다. 이름은 자유롭게 바꿔도 됩니다.

| 명령어 | 기능 | 권한 |
|---|---|---|
| `!명령어` `!노래 신청` `!노래 삭제` `!노래 목록` `!노래` | 명령어 목록 링크 · 노래 신청/취소/대기열/현재 곡 | 시청자 |
| `!방제` `!카테고리` `!업타임` | 방송 제목·카테고리·방송 시간 조회 | 시청자 |
| `!추가` `!삭제` `!수정` | 채팅으로 echo 명령어 관리 | 매니저 |
| `!방제 수정` `!카테고리 수정` `!공지` | 방송 정보 변경 | 매니저 |
| `!에이전트` | [에이전트](/manual/agent#채팅에서-부르기)를 채팅으로 호출 | 스트리머 |
| `!테스트` | 단순 응답 예시 | 모두 |

챗봇의 응답은 치지직 채팅 규칙에 따라 한 번에 100자까지입니다.
