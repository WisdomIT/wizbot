위즈봇은 치지직 방송을 위한 도우미입니다 — 챗봇 명령어, 노래 신청과 뮤직 플레이어, 네이버 카페 대문 자동화를 제공합니다.

## 사용 신청

1. [로그인 페이지](/login)에서 치지직 계정으로 로그인합니다.
2. 아직 승인되지 않은 계정은 신청 화면으로 이동합니다. 신청 사유를 적어 제출하면 운영자에게 전달됩니다.
3. 운영자가 승인하면 다음 로그인부터 스트리머 콘솔을 쓸 수 있습니다.

## 콘솔 둘러보기

승인 후 로그인하면 스트리머 콘솔이 열립니다. 왼쪽 메뉴 기준으로:

| 메뉴 | 하는 일 |
|---|---|
| 봇 › 명령어 / 반복 | 챗봇 명령어와 반복 메시지 관리 |
| 노래 › 뮤직플레이어 / 즐겨찾기 / 재생 기록 | 노래 신청 대기열과 재생 관리 |
| 카페 › 연동 설정 / 대문 이미지 / 유튜브 채널 | 네이버 카페 대문 자동화 |
| 설정 › 계정 설정 / 링크 설정 / 변경 기록 | 채널 설정과 변경 이력 |
| 소식 › 공지사항 / 문의사항 | 위즈봇 소식 확인과 운영자 문의 |

화면 오른쪽 아래의 ✨ 버튼은 **에이전트**입니다 — 설정을 대신 조회하고 바꿔주는 채팅 도우미입니다. [에이전트 안내](/manual/agent)를 참고하세요.

## 시청자에게 알려줄 주소

시청자용 페이지는 `bot.wisdomit.co.kr/{채널 ID}/command` 형태입니다. 챗봇의 `!명령어` 명령어가 이 주소를 채팅으로 알려줍니다.
