봇 › **통계**에서 시청자가 채팅으로 명령어를 부른 기록을 봅니다. 위쪽 버튼으로 **최근 7일 / 최근 30일**을 고릅니다.

## 무엇을 보여주나

- **호출 요약** — 기간 내 전체 호출, 봇이 응답한 호출, 응답하지 못한 호출(없는 명령어·용법 오류·권한 없음).
- **많이 쓰인 명령어** — 호출 수 순위. 상위 20개까지 이름을 보이고 나머지는 「기타」로 묶습니다. 삭제된 명령어는 「(삭제됨)」으로 표시됩니다.
- **누적 호출 추이** — 기간 시작부터 그날까지 쌓인 호출 수를 선으로 그립니다. 호출 수 상위 20개 명령어는 색으로 구분하고 나머지는 「기타」입니다. 범례에 마우스를 올리면 그 명령어만 강조되고, 그래프에 마우스를 올리면 그날까지의 누적 내역이 보이고, 「표로 보기」를 열면 같은 값을 표로 봅니다.
- **응답하지 못한 호출** — 시청자가 입력한 이름 그대로 종류별로 셉니다.
  - *없는 명령어*: 등록되지 않았거나 꺼둔 명령어를 불렀습니다.
  - *용법 오류*: 기능 명령어를 인수 없이 부르는 등 안내 문구로 끝났습니다.
  - *권한 없음*: 매니저·스트리머 전용 명령어를 시청자가 불렀습니다.

## 집계 기준

- 날짜 경계는 **한국 시간 자정**입니다.
- 호출 기록은 **최근 90일**만 보관합니다. 명령어 페이지의 총 호출 수는 기록이 지워져도 누적으로 남습니다.
- 이름을 바꿔도 같은 명령어로 합쳐 셉니다. 삭제하고 같은 이름으로 다시 만들면 새 명령어입니다.
- 채팅 에이전트도 같은 통계를 읽습니다 — "요즘 제일 많이 쓰는 명령어 뭐야?", "시청자들이 없는 명령어 뭐 치고 있어?" 처럼 물어보면 조회해서 답합니다.
