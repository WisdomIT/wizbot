위즈봇 플레이어는 노래를 송출하는 데스크톱 앱입니다(Windows·macOS). [다운로드 페이지](/download)에서 설치합니다 — 서명 인증서가 없어 첫 실행 시 OS 경고가 뜨는데, 페이지의 안내를 따라 진행하면 됩니다.

## 전역 단축키

다른 프로그램을 쓰는 중에도 동작합니다. 노래 설정(앱에서 열었을 때)에서 끄거나 키를 바꿀 수 있습니다.

| 동작 | 기본 키 |
|---|---|
| 재생/일시정지 | `Ctrl(⌘)+Shift+P` |
| 정지 | `Ctrl(⌘)+Shift+S` |
| 다음 곡 | `Ctrl(⌘)+Shift+N` |

키는 수식키(Ctrl/⌘/Alt/Shift) + 문자·숫자 조합이어야 하고, 서로 겹칠 수 없습니다. 다른 프로그램이 이미 차지한 키는 동작하지 않으니 그럴 땐 다른 조합으로 바꿔주세요.

## 창 모드

- **데스크톱 모드** — 콘솔의 뮤직플레이어와 같은 화면.
- **미니 플레이어** — 폭이 좁은 항상 위 컨트롤러. 재생/다음 곡/한 곡 반복/볼륨/재생 위치와 대기열 토글만 담았습니다.

창을 닫아도 앱은 **트레이에 남아 재생을 이어갑니다**. 트레이 아이콘을 클릭하면 창이 다시 열리고, 우클릭 메뉴에서 현재 곡 확인·재생 조작·앱 정보·종료를 할 수 있습니다. 종료는 트레이 메뉴에서만 됩니다.

## 유튜브 프리미엄

설정의 **유튜브 로그인**으로 별도 창에서 유튜브에 로그인하면, 프리미엄 계정의 경우 광고 없이 재생됩니다. 로그아웃해도 위즈봇 로그인은 유지됩니다.

> OBS 브라우저 소스를 쓰는 경우: OBS 에 브라우저 소스를 하나 더 만들어 `https://www.youtube.com` 을 열고 [상호작용] 창에서 로그인하면 같은 효과를 얻을 수 있습니다.

## 자동 실행·업데이트

- **컴퓨터 시작 시 자동 실행**을 켜면 부팅할 때 창 없이 트레이로 조용히 시작합니다. 계정이 아니라 그 컴퓨터의 설정입니다.
- 업데이트 — **Windows**: 새 버전을 자동으로 내려받아 트레이 메뉴·앱 배너의 「새 버전 (x.y.z) 설치」로 즉시 설치하거나, 앱을 종료할 때 자동 설치됩니다. **macOS**: 새 버전 알림이 뜨면 버튼으로 dmg 를 내려받아 직접 교체 설치합니다.
