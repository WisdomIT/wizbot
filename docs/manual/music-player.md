시청자가 채팅으로 신청한 노래를 방송에 재생합니다. 노래 › **뮤직플레이어**에서 현재 곡과 대기열을 관리합니다.

## 대기열

- 시청자는 채팅 명령어(`!노래 신청` 등)로 신청합니다 — [기능 명령어 안내](/manual/chatbot-functions#노래) 참고.
- 스트리머는 화면에서 직접 곡을 추가할 수 있고, 이때는 신청 제한이 적용되지 않습니다.
- 드래그로 순서를 바꾸고, 지금 재생·삭제·비우기를 할 수 있습니다.

시청자 신청 제한은 노래 설정의 **신청 제한**에서 조절합니다:

- **대기열 최대 곡 수** — 기본 30곡, 최대 100곡
- **1인당 신청 곡 수** — 기본 1곡, 무제한으로 풀 수도 있습니다 (판별은 닉네임이 아니라 신청자 계정 기준)

그 외에 10분 이하 영상만, 이미 대기 중인 곡은 중복 신청 불가 규칙이 항상 적용됩니다.

기능 자체를 쉬려면 노래 설정 **최상단의 「노래 신청 기능」 스위치**를 끄세요. 꺼져 있는 동안에는 신청이 등록되지 않고, 노래 관련 채팅 명령어(신청·삭제·목록·현재 곡)에 챗봇이 "노래 신청 기능이 꺼져 있습니다"로 답하며, 시청자 플레이리스트 페이지에도 안내가 표시됩니다. 스트리머가 화면에서 직접 곡을 추가·재생하는 것은 그대로 됩니다. 에이전트에게 "1인 2곡으로 바꿔줘", "노래 신청 꺼줘"처럼 요청해도 됩니다.

## 송출 — 소리는 어디서 나오나

실제 소리는 **송출 소스**가 냅니다. 뮤직플레이어 상단 「송출」에 두 가지가 항상 함께 보입니다.

| 송출 소스 | 설명 |
|---|---|
| **플레이어 앱** | [데스크톱 앱](/manual/player-app)을 설치해 켜두면 아래 목록에 컴퓨터 이름으로 나타납니다 |
| **OBS 브라우저 소스** | 표시된 재생 페이지 주소를 OBS 브라우저 소스로 추가합니다. 주소에는 토큰이 들어 있으니 방송에 노출하지 마세요(재발급 가능 — 재발급하면 기존 주소는 즉시 무효) |

앱이나 브라우저 소스가 연결되면 그 아래에 **지금 연결된 플레이어 목록**이 뜹니다. 각 줄의 오른쪽 버튼으로:

- **찾기(👁)** — 어느 창인지 확인합니다. OBS 브라우저 소스는 화면이 **빨간 테두리로 빛나며 「이 브라우저 소스가 찾기에 의해 호출됨」** 이 뜨고 띵동 소리가 3번 납니다. 앱은 **작업 표시줄 아이콘이 깜빡이고(Windows) 독 아이콘이 뜁니다(macOS)**, 앱 화면에 「이 앱이 찾기에 의해 호출됨」 이 뜨며 띵동 소리가 납니다.
- **송출 소스로 설정(▶)** — 그 플레이어가 소리를 냅니다. 설정된 창에는 「송출 소스로 설정됨」 이 잠깐 표시됩니다. 소리는 **한 곳에서만** 나고 나머지는 「대기」 로 남습니다.

처음에는 **가장 먼저 연결된 플레이어가 자동으로 선택**되므로, 앱을 설치해 켜기만 해도 소리가 납니다. 선택은 컴퓨터를 껐다 켜도 유지됩니다(각 플레이어에 고유 ID 가 있습니다). 「송출 소스 선택 해제」 를 누르면 어느 곳에서도 소리가 나지 않습니다.

### 어떤 걸 쓰면 좋을까

| 상황 | 추천 |
|---|---|
| 음악용 오디오 채널을 방송에서 **분리**하고 싶다 | **OBS 브라우저 소스** — 브라우저 소스의 오디오를 별도 트랙으로 다룰 수 있습니다 |
| **전역 단축키**로 빠르게 재생/정지/다음 곡을 조작하고 싶다 | **플레이어 앱** |
| 단축키도 쓰고 오디오 채널도 분리하고 싶다 | **둘 다** — 앱을 켜서 단축키·미니 플레이어로 조작하되, 송출 소스는 **OBS 브라우저 소스**를 선택합니다. 조작은 서버를 거치므로 소리는 OBS 에서 납니다 |

> ⚠️ 한 OBS 안에 같은 재생 페이지를 브라우저 소스로 **둘 이상** 넣으면 OBS 가 저장소를 공유하는 탓에 재시작 때 두 소스의 ID 가 서로 바뀔 수 있습니다. 재생 페이지는 OBS 하나에 하나만 두세요.

상단 상태 줄에는 선택한 플레이어의 **연결됨 / 연결 안 됨**과, 오른쪽 끝 작은 점으로 **실시간 연결** 상태가 보입니다. 서비스 업데이트 등으로 끊기면 「재연결 중」 으로 바뀌고 스스로 다시 붙습니다. 재생을 눌렀는데 선택한 플레이어가 켜져 있으면서도 10초 넘게 응답이 없으면 **「송출 소스가 재생에 응답하지 않습니다」** 경고가 뜹니다 — 「찾기」 로 그 창을 확인하거나 앱·브라우저 소스를 다시 켜보세요.

## 자막

재생 페이지에는 현재 곡 제목 자막이 함께 표시됩니다. 노래 설정에서 **항상 표시** 또는 **곡이 바뀔 때 몇 초만 표시**(기본 — 15초)를 고를 수 있고, 글꼴은 [테마](/manual/settings#테마)를 따릅니다.

## 자동 재생

대기열이 비었을 때 **대표 즐겨찾기**에서 한 곡을 무작위로 골라 이어서 재생합니다(같은 곡이 연속으로 걸리지 않게 직전 곡은 제외). 신청자에는 「자동 재생」으로 표시됩니다. 기본으로 켜져 있고, 노래 설정에서 끌 수 있습니다.

곡이 **3번 연속 재생되지 않으면** 다음 곡으로 넘기지 않고 멈춥니다. 한두 곡이 아니라 모든 곡이 실패한다면 곡이 아니라 재생 창의 문제(임베드 차단·네트워크·유튜브 로그인 상태)일 가능성이 크고, 그대로 두면 자동 재생이 즐겨찾기를 끝없이 넘기며 정지도 되지 않기 때문입니다. 뮤직플레이어 상단 배너에 마지막 실패 원인이 표시되며, 재생 창을 점검한 뒤 **「다시 시작」**(또는 ▶)을 누르면 재개됩니다.

## 즐겨찾기

노래 › **즐겨찾기**는 미리 담아두는 재생목록입니다 — 최대 20개, 목록당 500곡.

- 유튜브 **재생목록 주소로 한 번에 가져오기**를 지원합니다.
- 자동 재생은 **대표**로 지정한 즐겨찾기에서 곡을 고릅니다. 처음 시작하면 「위즈 추천 플레이리스트」가 대표로 만들어져 있습니다 — 이름을 바꾸거나 지우고 직접 꾸며도 됩니다.
- 「대기열로」를 누르면 담긴 곡을 (순서대로 또는 섞어서) 대기열에 넣습니다 — 신청 제한이 적용되지 않습니다.
- 지금 재생 중인 곡이 최근 30일 동안 3번 이상 끝까지 재생됐는데 대표 즐겨찾기에 없으면, 플레이어의 하트 버튼 위에 **「최근 N번 재생」** 배지가 작게 뜹니다. 마우스를 한 번 올리면 사라지고 그 곡에는 다시 뜨지 않습니다. 즐겨찾기에 담으면 조건이 풀립니다.

## 재생 기록

노래 › **재생 기록**에서 재생됨/넘김/취소됨/재생 실패를 확인하고, 기록에서 바로 다시 신청할 수 있습니다. 재생 실패에는 원인(「임베드 차단」 「삭제·비공개 영상」 등)과 어느 창(앱/OBS)에서 실패했는지가 함께 남습니다. 노래 설정에서 **시청자 공개**를 켜면 시청자 페이지에도 기록이 보이고, 개별 항목만 숨길 수도 있습니다.
