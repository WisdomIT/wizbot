기능(function) 명령어를 등록할 때 고르는 기능들의 상세 안내입니다. 아래 사용법의 `!이름` 은 등록할 때 정한 명령어 이름입니다.

## 명령어 관리

| 기능 | 사용법 | 설명 |
|---|---|---|
| echo 명령어 추가 | `!이름 <명령어> <응답>` | 채팅으로 echo 명령어를 만듭니다. 예) `!추가 인사 안녕하세요!` |
| echo 명령어 수정 | `!이름 <명령어> <새 응답>` | **모든** echo 명령어를 채팅으로 수정할 수 있습니다 |
| echo 명령어 수정 (지정) | `!이름 <새 응답>` | **정해둔 echo 하나만** 수정합니다 — 등록할 때 대상 echo 를 옵션으로 고릅니다 |
| echo 명령어 삭제 | `!이름 <명령어>` | 채팅으로 echo 명령어를 지웁니다 |

**「수정」과 「수정 (지정)」의 차이** — "echo 명령어 수정"은 이름을 지정해 아무 echo 나 고칠 수 있어 매니저 권한에 어울립니다. "echo 명령어 수정 (지정)"은 대상이 하나로 고정되어 있어 **특정 명령어만 시청자에게 열어줄 때** 씁니다.

> 예: `!멤버` 라는 echo 가 있을 때 — 「echo 명령어 수정 (지정)」으로 대상을 `멤버` 로 고른 `멤버 수정` 명령어를 시청자 권한으로 만들면, 누구나 `!멤버 수정 새 내용` 으로 `!멤버` 의 응답만 바꿀 수 있습니다.

## 노래

| 기능 | 사용법 | 설명 |
|---|---|---|
| 노래 신청 | `!이름 <검색어 또는 영상 ID>` | 유튜브에서 찾아 대기열에 넣습니다. 예) `!노래 신청 LUCY 개화` |
| 노래 삭제 | `!이름` 또는 `!이름 <순번>` | 인수 없이 쓰면 본인이 신청한 마지막 곡 취소. 순번 지정 삭제는 매니저부터 가능합니다 |
| 노래 목록 | `!이름` | 대기 곡 수와 플레이리스트 링크 |
| 현재 노래 | `!이름` | 재생 중인 곡을 알려줍니다 |

## 방송 정보 (치지직)

| 기능 | 사용법 | 설명 |
|---|---|---|
| 방송 제목/카테고리/시간/시청자 수 조회 | `!이름` | 현재 값을 채팅으로 알려줍니다 |
| 방송 제목 수정 | `!이름 <제목>` | |
| 방송 카테고리 수정 | `!이름 <검색어>` | 치지직에서 검색해 첫 번째 결과를 적용합니다. 예) `배그` → PUBG: 배틀그라운드 |
| 방송 공지 설정 | `!이름 <공지>` | 100자까지 |

방송 정보 기능은 치지직 연동으로 동작합니다. "치지직 연동이 만료되었습니다"라고 답하면 사이트에서 다시 로그인해주세요.

## 반복 메시지

| 기능 | 사용법 | 설명 |
|---|---|---|
| 반복 명령어 추가 | `!이름 <메시지>` | 반복 메시지를 만듭니다. 주기는 반복 메뉴의 기본 주기가 적용됩니다 |
| 반복 명령어 삭제 | `!이름 <id>` 또는 `!이름 all` | id 는 만들 때 채팅으로 알려줍니다 |
