## 계정 설정

설정 › **계정 설정**에서:

- **챗봇 사용** — 끄면 1분 안에 채팅 연결이 해제되고, 켜면 1분 안에 다시 연결됩니다.
- **목록 노출** — 위즈봇 첫 화면의 채널 목록에 내 채널을 표시할지 정합니다.
- 탈퇴도 여기서 합니다.

## 링크 설정

설정 › **링크 설정**의 링크는 위즈봇 첫 화면의 채널 카드와 시청자 페이지 사이드바에 노출됩니다 — 디스코드·유튜브·후원 링크 등.

- 최대 12개, 이름은 20자까지, 주소는 http(s) 만 됩니다.
- 아이콘을 목록에서 고를 수 있고, 순서는 위/아래 버튼으로 바꿉니다.

## 테마

설정 › **계정 설정**의 테마에서 시청자 페이지·콘솔·플레이어 앱·OBS 자막(글꼴)의 모습을 바꿉니다.

- 배경 색·사이드바 색·강조 색, 라이트/다크(방문자 설정 따름·라이트 고정·다크 고정), 글꼴 14종.
- 글자가 잘 안 보이는 색 조합이면 대비 경고가 표시됩니다. 저장 전 미리보기로 확인하세요.

## 변경 기록

설정 › **변경 기록**에는 이 채널의 설정 변경이 전부 남습니다 — 누가(본인·관리자·채팅 호출자·에이전트) 언제 무엇을 바꿨는지. 관리자가 대신 변경한 것도 그대로 보이므로 투명하게 확인할 수 있습니다.
