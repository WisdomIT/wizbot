네이버 카페 대문에 **방송 상태 이미지**(방송 중/종료에 따라 제목·카테고리·시청자 수·썸네일이 자동으로 바뀌는 이미지)와 **유튜브 최신 영상**을 자동으로 반영합니다. 한 번 설정하면 방송을 켜고 끌 때마다 위즈봇이 대문을 갱신합니다.

> 이 기능은 에이전트가 대신 설정해줄 수 없습니다 — 아래 단계를 따라 직접 설정해주세요.

설정은 카페 › **연동 설정**의 4단계를 위에서부터 진행합니다.

![연동 설정 화면](/images/manual/cafe-setting-overview.png)

## 1. 카페 연결

1. 페이지 상단의 사용 토글을 켭니다.
2. 카페 주소(예: `https://cafe.naver.com/내카페`)를 입력하고 연결합니다.
3. **가입 신청**을 누르면 위즈봇 봇 계정의 카페 가입을 운영자에게 요청합니다. 상태가 「운영자 가입 대기」로 바뀝니다.
4. 운영자가 봇 계정으로 가입을 신청하면 상태가 「가입 신청됨 · 승인 대기」가 됩니다 — 이제 스트리머(카페 매니저) 차례입니다.

![카페 연결 단계](/images/manual/cafe-setting-join.png)

## 2. 봇 계정 권한

카페 관리 페이지에서 봇 계정의 가입을 **승인**하고, 멤버 등급을 **디자인 스탭**(또는 매니저)으로 지정합니다. 디자인 스탭이어야 봇이 대문을 편집할 수 있습니다.

![네이버 카페에서 디자인 스탭 지정](/images/manual/cafe-naver-staff.png)

지정을 마쳤으면 연동 설정으로 돌아와 **권한 확인**을 누릅니다. 잠시 후 「권한 확인됨」이 되면 다음 단계로 넘어갑니다. 「권한 없음」이 뜨면 승인·등급 지정이 됐는지 다시 확인해주세요.

## 3. 방송 상태 위치 설정

대문의 어느 자리에 방송 상태 이미지와 유튜브 영상을 넣을지 고릅니다.

![방송 상태 위치 설정](/images/manual/cafe-setting-picks-btn.png)

1. **대문 불러오기**를 누르면 현재 카페 대문이 네이버와 동일하게 렌더되어 표시됩니다.
2. 위쪽에서 지정할 항목(**현재 방송 상태 이미지** / **현재 유튜브 영상**)을 고른 뒤, 미리보기에서 그 항목이 들어갈 요소를 클릭합니다. 지정한 요소는 해당 블록으로 교체되며 크기는 그 요소를 따릅니다.

![요소를 클릭해 지정](/images/manual/cafe-setting-picks-picking.png)

3. 두 항목 모두 선택 사항입니다 — 지정하지 않은 항목은 대문에 반영하지 않습니다.
4. 위치를 저장하면 대문에 반영됩니다. [대문 이미지](#3-방송-상태-위치-설정)나 [유튜브 채널](#유튜브-채널) 설정이 아직 없으면 자리만 저장해 두고, 설정이 완료되는 대로 반영됩니다.

![지정 완료 상태](/images/manual/cafe-setting-picks-picked.png)

방송 상태 이미지의 내용(글자 위치·색·배경)은 카페 › **대문 이미지**에서 꾸밉니다:

- 방송 중 / 방송 종료 **두 벌**을 각각 만듭니다. 배경 이미지를 올리고(2MB 이하), 그 위에 제목·카테고리·시청자 수·썸네일 영역을 배치합니다.
- 파워포인트처럼 드래그로 옮기고, 스냅 가이드·정렬 버튼·수치 입력으로 맞춥니다. 글자 크기는 영역의 세로 크기에서 자동으로 정해집니다.

![대문 이미지 에디터](/images/manual/cafe-editor.png)

## 4. 반영 현황

상태가 「동작 중」이면 끝입니다 — 이후에는 방송을 켜고 끌 때, 제목·카테고리·시청자 수가 바뀔 때 위즈봇이 대문을 자동으로 갱신합니다. 마지막 변경 시각과 현재 대문 이미지를 이 단계에서 확인할 수 있습니다.

![반영된 카페 대문 예시](/images/manual/cafe-result.png)

## 유튜브 채널

카페 › **유튜브 채널**에서 채널 주소(`https://www.youtube.com/@핸들` 등)를 입력하면 채널의 **업로드 재생목록**이 대문에 embed 됩니다 — 새 영상을 올리면 별도 설정 없이 자동으로 최신 영상이 보입니다. 위치·크기는 연동 설정 3단계에서 지정합니다.

![유튜브 채널 연결](/images/manual/cafe-youtube.png)

## 문제가 생기면

- **「봇 계정의 네이버 세션이 만료되어 대문 갱신이 중단되었습니다」** — 운영자에게 이미 알림이 간 상태입니다. 운영자가 갱신하면 밀린 작업부터 자동으로 재개되니 기다려주세요.
- 대문이 갱신되지 않으면 연동 설정의 상태 표시를 확인하고, 「권한 없음」이면 봇 계정의 카페 등급이 바뀌지 않았는지 확인해주세요.
